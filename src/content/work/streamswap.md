StreamSwap lets a project sell its token over time rather than in a single instant.
A stream opens a window instead of one crowded block — anyone can join while it is
open, and everyone settles at the same final price.

I architected and developed the smart contracts — the core of the protocol. I've since
stepped away from it; the code stays public.

**Chain:** Osmosis (Cosmos)
**Stack:** Rust, CosmWasm
**Code:** [streamswap-contracts](https://github.com/StreamSwapProtocol/streamswap-contracts)
